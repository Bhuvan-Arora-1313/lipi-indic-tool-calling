# results/

Generation and evaluation outputs (model responses, BFCL score files) for
Exp 0-5, organized by experiment/model/language/condition.

Not the same as `bfcl_eval/result/` and `bfcl_eval/score/` (BFCL's own default
output locations) -- outputs land there first via `bfcl generate`/`bfcl
evaluate`, then get organized into this folder per experiment for reporting.
