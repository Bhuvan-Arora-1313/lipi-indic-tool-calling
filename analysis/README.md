# analysis/

Error taxonomy classification and result analysis, using MLCL's full
8-category severity scheme (Section 6 of `Indic_ToolCalling_Project_Plan.md`):
Syntax Error, Function-Level Error, then Language Mismatch and English-value
errors split by Wrong Value / Relevant but Incorrect / Same Meaning.

This supersedes the simplified 4-category taxonomy used in the archived pilot
(`archive/pilot-hindi-tamil-simple-python` branch).
